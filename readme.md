## 🎯 Propósito del Proyecto

El objetivo principal de este proyecto fue aplicar las estructuras básicas de **HTML, CSS y JavaScript**.

A lo largo del desarrollo, pude observar las particularidades sintácticas y estructurales de cada lenguaje. Si bien cada uno permite construir soluciones simples o complejas de manera independiente, su verdadero potencial se evidencia al integrarlos, conformando una arquitectura en capas que da vida y dinamismo al proyecto.

## 🌐 Descripción General del Sitio Web

El sitio web desarrollado está orientado a un modelo de **e-commerce** con una propuesta interactiva para el usuario, integrando elementos didácticos y educativos.

Su narrativa se centra en la **evolución tecnológica**, permitiendo al usuario experimentar un recorrido por distintos artefactos históricos que, en muchos casos, las nuevas generaciones desconocen.

Esta propuesta busca poner en valor el acelerado avance tecnológico mediante un formato atractivo y accesible.

---

## 📷 Módulo de Historia y Productos

Cada semana se presenta una historia distinta.

En esta entrega en particular, el enfoque está puesto en la **evolución de las cámaras fotográficas a lo largo del tiempo**.

El usuario puede simular un viaje temporal que lo conduce hacia la sección de productos.

### 🔎 Buscador

El buscador implementado permite filtrar resultados mediante:

- Año
- Palabras clave
- Marca

En caso de no encontrar coincidencias, el sistema informa al usuario de manera clara.

### 🛒 Carrito de compras

Los productos pueden ser añadidos al carrito de compras, generando un mensaje de confirmación ante cada acción.

No existe límite de productos por usuario.

Dentro del carrito se implementó un sistema que permite:

- Contabilizar unidades individuales
- Calcular el total general
- Aumentar cantidades
- Disminuir cantidades
- Eliminar productos individualmente
- Visualizar imagen, nombre y precio de cada producto
- Continuar navegando sin perder el contenido del carrito

### 💳 Proceso de compra

Una vez confirmada la compra, el sistema redirige al usuario al formulario de registro y selección de medio de pago.

La transacción simula una compra real y muestra un visor tipo **ticket** con los datos de la operación.

Al finalizar:

1. El carrito se vacía automáticamente.
2. El usuario recibe la confirmación de la operación.
3. El sistema redirige nuevamente a la sección de productos.

## 📩 Formulario de Contacto y Reseñas

La sección de contacto incluye un formulario funcional implementado mediante **Formspree**.

El formulario permite:

- Realizar consultas
- Coordinar acciones
- Enviar reseñas

El sistema identifica el tipo de mensaje recibido y, en caso de tratarse de una reseña, la inserta automáticamente en el carrusel de comentarios visibles al público.

## 🤖 Reflexión y Uso de Herramientas Complementarias

La experiencia en cuanto a creatividad versus resultados obtenidos fue satisfactoria.

Si bien hubiese deseado lograr una simulación de viaje temporal más inmersiva, las limitaciones derivadas del uso exclusivo de herramientas gratuitas de diseño lo impidieron parcialmente.

Durante el desarrollo, recurrí intensamente al uso de **inteligencia artificial**, particularmente a **ChatGPT**, como herramienta de asistencia para resolver diversos desafíos técnicos.

Entre ellos se destacan:

- Efectos visuales en 3D
- Manejo de eventos
- Enlaces e hipervínculos
- Implementación de funciones en JavaScript
- Resolución de problemas técnicos
- Optimización y organización del código

Las soluciones obtenidas fueron posteriormente adaptadas al proyecto con el objetivo de mantener un código organizado, eficiente y escalable.

Este proyecto no solo representó una práctica técnica en **HTML, CSS y JavaScript**, sino también un ejercicio de integración creativa y uso responsable de tecnologías emergentes como la **inteligencia artificial**.
